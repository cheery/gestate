# substrates/ — the faces that come with gestate

Reusable substrate pieces, offered by the `template` command beside
`templates/` — a face is pasted into your file and becomes yours, the
same rule every template keeps.  Each file is one piece: its `#:`
lines are what the palette shows, and the body is what lands at the
caret.

The pieces here are the ones `examples/` kept rewriting: a scope's
trace, a fader, a meter.  A piece earns its place the way everything
does — by the second file that wanted it.
