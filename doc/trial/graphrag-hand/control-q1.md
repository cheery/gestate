# What Checks the Keeper, What Spreads the Method

## Restraint Inside the Role

The keeper's own attention is treated as a scarce resource, not an infinite one. `capacity-is-not-a-caller` names the rule directly: software is kept rather than written, and there is only one keeper, with three legitimate pulls on that keeper's limited weekly capacity (`doc/memory/capacity-is-not-a-caller.md`, `doc/memory/README.md`). That scarcity is structured, not merely felt: **the-keepers-evening**, formalized in `keeper.md`, is standard work — read the lamps, open the decisions batch, measure one rule, pass over the pile, rotate monthly — so the keeper's judgment operates inside a fixed weekly procedure rather than drifting into ad hoc attention (`doc/memory/README.md`, `journal/2026-08.md`).

A second check is structural rather than personal: **the fire**, where dated records in the ledger are reviewed and humans assess state changes and "hold the process" (`doc/notes/notes-on-corrections.md`). This routes accumulated drift through a recurring communal review rather than leaving it to private discretion.

A third and more pointed check addresses the danger of self-serving judgment: `doc/memory/the-evaluation-loop.md` observes that a session judging the method is itself a product of that method, so its verdict is suspect — "the real check should be routed to a stranger" (`doc/memory/README.md`, `journal/2026-08.md`, `journal.md`). This is enacted concretely through `card:stranger-test.md`, where someone who does not read code for a living meets the artifact directly, and a wrong guess that merely happened to work is treated as worse than an honest stumble (`fixme.md`).

Finally, the keeper's qualification is framed so that doubt cannot be used to escape accountability: `the-keeper-is-the-qualification` holds that uncertainty is itself the qualification for keeping the tree, not a disqualification from it (`doc/memory/the-keeper-is-the-qualification.md`), which keeps the keeper answerable rather than letting confidence stand in for correctness.

## What Would Spread the Method
