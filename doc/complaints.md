The sweep `card:error-messages.md` asked for, kept as a list rather than as a memory.  Each row is one `raise` in `gestate/`, and the verdict beside it was written next to that raise — on the site, the function, the file or the error class, whichever is nearest.

**What the words mean.**

| verdict | who is standing in front of it | owes a place |
|---|---|---|
| `author` | a person wrote it, in their own file, on a line | **yes** |
| `command` | a person asked for it — about the request, not a line | no |
| `world` | the machine or the world outside refused | no |
| `machine` | this program failed its own invariant | no |

An `author` complaint may say `nowhere` instead, and then the reason is printed with it: the message is about a whole program — exhaustiveness, coherence, monotonicity — and a line number would be a fiction.  *That is a decision, not a gap, which is the whole reason this file exists.*
