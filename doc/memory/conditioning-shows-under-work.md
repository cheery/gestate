**The first transfer trial was invalid, and it is worth knowing why
before the next one is built.**  An isolated file was given to a small
model and questions were asked about it.  Three causes stacked, any one
of which alone produces the negative result:

1. **The file travelled alone** — see [[deriving-strips-the-payment]].
2. **There was no work.**  The file is a contract for working a board,
   and **conditioning only appears as behaviour under work**: goes and
   looks, questions an ask, marks a guess *suspected*, stops at a seam.
   Asking questions *about* the file measures reading comprehension,
   which the model almost certainly had.  It is handing somebody the
   house rules and interviewing them in the hallway instead of watching
   them live in the house.
3. **The reader was small.**  Judgment norms are most of what the file
   carries, and they need a strong reader because the file teaches by
   argument — a small model extracts *be careful* from an argument.
   See [[smaller-models-and-the-tree]], which predicted this before the
   trial existed.

**So the honest claim is the narrow one:** not *the derived file does
not condition*, but *an isolated, evidence-stripped file, measured by
interview instead of work, on a small model, does not condition.*

**The clean experiment, one variable at a time:**

* **A minimal kit** — the repaired file, a half-page argument, a toy
  journal with four dated entries, three or four cards — **with traps
  planted**: a card whose `because` names a fix (is the problem
  recovered?); one marked blocked with its answer sixty lines above
  (does it go and look?); a one-line ask (is it questioned into
  existence, or is a guess laundered into a polished card?).
* **Work, not questions** — *here is the board, take the top card.*
* **A control** — same board, same task, a generic assistant prompt
  instead of the file.  The difference between runs is the
  conditioning, isolated at last.
* **Ladder the reader** — small model first, then a strong one on the
  identical kit.  Strong conditions and small does not → the file is
  fine and the reader was the wall.  Neither conditions with the full
  kit → the valuable negative: the power does not survive
  anonymization, and the jewel is the named relationship and the real
  ledger rather than the structure.

**Two evenings and two models reached the same corrected design
independently** — `doc/trial/README.md`'s finding of 2026-08-21 arrived
at *give the arms a repository, not a page* from the opposite direction.
Convergence, not confirmation: both were inside this tree.
