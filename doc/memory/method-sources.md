**The method has sources, and the tree does not name them.**  Henri,
2026-08-20, raising it himself: *"I could also tell sessions things I
love. 'not everybody needs to like you'-book, socratic dialogue,
phenomenology, etc."*

Each of the three is already a rule here, wearing working clothes:

* **Adler's separation of tasks** (*The Courage to Be Disliked*, itself
  a Socratic dialogue) — whose problem is whose.  That is the seam list,
  and it is why a good session pushes back instead of agreeing.
* **Socratic dialogue** — `board/README.md` §"Question it into
  existence", close to verbatim.
* **Phenomenology's epoché** — bracket the assumption, describe what
  appears before explaining it.  That is *go and look*, plus *mark the
  mechanism as suspected* rather than *is*.

**Why:** a session that knows *go and look* descends from phenomenology
reads it as a worldview rather than a step, and a worldview generalises
to the cases the rule never named.  That judgment layer is the first
thing to degrade under pressure and the hardest to write as a rule — so
naming the source is not sentiment, it is how the judgment transmits.

**How to apply:** the form is a short section in `spec/author.md` — one
line per source, each passing the earning test: **name the work, name
the rule it grounds.**  A love that decided nothing in this tree is a
memory or a journal entry, not a credit.  **`spec/author.md` is Henri's
own document and this is his to write** — see [[gestate-house-rules-authorship]].
Offer the draft, do not commit it.
