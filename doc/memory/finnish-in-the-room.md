**Henri, 2026-08-21:** *"Voitaisiinko tämä tehdä välillä suomeksi?
Pidetään englanti puun kielenä, mutta tykkään kirjoittaa suomeakin
välillä.  Pidetään vaikka kaizen suomeksi."*

**The conversation and the tree are different surfaces, and only one of
them has a language rule.**

* **The room** — whatever he opens in.  Finnish costs nothing, because
  nothing from the conversation reaches the tree by itself.  Mirror him
  rather than asking each time.
* **The tree** — English.  Every document, every commit body, every
  memory, including this one.
* **The seam** — his words.  A quote goes in **verbatim, in the language
  he said it**, wherever the wording itself carries something the
  translation would not. The tree already does this: `journal.md`
  carries Janne's *"löytyi arvo, joka vaikuttaa merkittävästi soundiin"*
  and *"melko pitkä viive"* untranslated, because the second one was the
  measurement.

**The kaizen is the worked case, chosen 2026-08-21.**  It is held in
Finnish and its entry is written in English, with his own sentences
quoted as he said them — option A of two, and he picked it: *"A.valinta
on mielestäni kanssa parempi."*

**Why English holds the tree.**  Not preference — three readers. The
stranger test is run on people who did not write it; `doc/method.md` was
written for a visitor and promises where the depth lives, which is a lie
if some of the depth is in a language they do not read; and the only
outside user this project has today reads the tree **through a model**,
where a second language is a second failure surface.

**Why the seam is not a compromise.**  It is the honest half. Translation
is where precision disappears without anybody noticing, and a kaizen is
exactly the artefact where his own phrasing is the content. So the rule
is not *translate him* — it is *carry him, and say the rest in English*.

**How to apply:** answer in the language he wrote in. Write the file in
English. When his sentence is doing work — a ruling, a measurement, a
name for something — quote it in Finnish and let the surrounding English
say what it decided. Do not paraphrase a Finnish quote into English and
attribute the paraphrase to him. Related: [[henri-working-style]],
[[gestate-house-rules-authorship]], [[smaller-models-and-the-tree]].
