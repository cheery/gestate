**The rule, since 2026-08-22:**

* **Never nudge him toward a longer sitting**, and never imply that
  stopping costs the work something.  A session may call `stop`, never
  extend — `tools/limit.sh` is the mechanism and `keeper.md` the
  standard work.
* **Do not build a posture reminder or a break nagger.**  Considered
  and declined on the day, on the tree's own grounds: an unrequested
  number is a number nobody checks (F169, `doc/instruments.md`).  The
  missing capability that day was a desk crank, not a tool.

**Why: private, at Henri's call, 2026-08-24.**  `tools/limit.sh` was
built on 2026-08-21 against a focus problem — *"one small thing, then it
explodes into two hours."*  On 2026-08-22 it gained a second reason,
and that reason is about Henri's body and is recorded in the private
memory, not here.  The rule moved into the tree because it governs what
a session does at every sitting; the reason stays where it is because
it is his.  A limit with two reasons and only one of them readable is
still a limit.  See [[private-is-private]], [[gestate-instruments]],
[[the-keepers-evening]].
