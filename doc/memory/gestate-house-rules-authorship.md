**`spec/author.md` is the author's, not a session's.**  Henri,
2026-08-19: *"Author.md was drafted by a session, but it will be kept up
by the author.  He may ask for help but he must read what stands in it.
That's the house rules here."*

**How to apply:** offer to check it, point at rows that have gone stale,
suggest wording — but he writes it and he reads it before it lands.  Do
not edit it unasked, and do not co-author the commit when the words are
his.  The same holds for [[gestate-board-goal]]'s `vision.md`, which
`board/README.md` already calls *the author's own document*.

**And gemba is opt-in.**  Henri, same evening: *"Sessions do not use it
by default because that would be waste, you have to tell that you're
wanting to gemba walk."*  It is a real workbench command
(`gestate/session.py:4804`), not only `python -m gestate.gemba say`.

`doc/instruments.md` used to say *"Use it whenever Henri is at the desk
while a session works"* — **corrected 2026-08-19** (`6596593`).  The page
had reasoned from the instrument's purpose to a policy of always, which
is how a thing built to save attention starts spending it.

**And the friends' contributions are older than they look.**
`examples/contrib/` has seven files, `Real_World_One.ges` among them.
Henri: *"they did that while ago… examples/contrib songs and their
tolerance as I was working too hard."*  See [[gestate-janne-and-mikko]].
