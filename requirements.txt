# gestate — dependencies.
#
# **The compiler needs nothing.**  Type-checking, the audio renderer, the
# score layout, `doc/ref` generation and the formatter are pure Python and
# import only the standard library:
#
#     python -m gestate.typecheck  examples/closure.ges
#     python -m gestate.audioperform examples/audio/sine.ges --oracle -o sine.wav
#     python -m gestate.reference
#
# Everything below is a *backend* or a *tool*.  Each one gates a set of
# tests and nothing else: the suite skips what it cannot import rather than
# failing, so a bare `pip install pytest` already runs most of it.
#
#     pip install -r requirements.txt
#
#     apt install clang llvm
#
# Versions are minimums, not pins — the numbers in the comments are what
# this was last verified against, on CPython 3.12.

# ── The suite ────────────────────────────────────────────────────────────
#
# The only hard requirement, and the reason this file exists.  Verified at
# 9.1.1.  No plugins are used or assumed; `-p no:randomly` appears in the
# commands in `plan.md` and is a harmless no-op when `pytest-randomly` is
# not installed.
#
# `pytest.ini` sits beside this file and holds one thing: two filters for
# warnings pygame raises on import, matched by message so that nothing
# else is hidden.
pytest>=8.0

# ── MIDI ─────────────────────────────────────────────────────────────────
#
# `gestate.midi` writes `.mid` files and `gestate.audiomidi` reads a live
# keyboard.  Verified at 1.3.3.
#
# Gates the MIDI half of `test_examples.py`, `test_music.py` and
# `test_audiomidi.py`, every one of them behind `pytest.importorskip`, so
# without it those skip and the rest of the suite is unaffected.
#
# `python-rtmidi` is the port backend: mido alone writes files and has no
# way to open a live keyboard.  Verified at 1.5.8.
mido>=1.3
python-rtmidi>=1.5

# ── Not a dependency: pygame ─────────────────────────────────────────────
#
# **Gone, with the two things that wanted it.**  `gestate.audiopygame`
# was retired outright (`spec/workbench.md`), and the canvas is drawn by
# the editor and by the plugin, both of which are Rust and take nothing
# from Python to do it.  What is left reaching for it is
# `gestate/gui.py`, which is obsolete.
#
# Do not install it on a new machine, and do not add it back for a test:
# a guard that skips is how every optional backend here behaves, and
# there is no longer a backend behind this one.

# ── Live audio ───────────────────────────────────────────────────────────
#
# PortAudio, for `gestate.audiolive` — the engine every player and editor speaks to.
# Verified at 0.5.5.
#
# **Not needed to run the suite, and the suite must never reach it.**
# `test/conftest.py` makes both routes to the sound card raise, naming the
# test that tried; `GESTATE_TEST_AUDIO=1` opens them again.  It is here
# because a machine that only runs tests does not want it and a machine
# someone plays on does.
sounddevice>=0.4

# ── Not a dependency ─────────────────────────────────────────────────────
#
# **numpy is not used anywhere in `gestate/` or `test/`.**  It may well be
# in the environment — it is convenient for measuring a spectrum from a
# scratch script, and several measurements quoted in `plan.md` were made
# that way — but nothing in the repository imports it, and the tests that
# assert a filter's slope write their own DFT rather than take the
# dependency.  Do not carry it across.

# ── System packages, which pip cannot install ────────────────────────────
#
# * **clang** — the native engine.  `spec/liveaudio.md` stage 4 emits LLVM
#   IR as text and shells out to `clang`; there is no `llvmlite`.  Every
#   test that needs it is behind `shutil.which("clang")` and skips without
#   it, so the suite passes on a machine with no compiler — it simply
#   stops checking the half of the project that generates code.  If the
#   new machine is meant to verify the engine, this is the one to install.
#
#   **That was not true until it was measured.**  Moving the suite to a
#   machine without clang failed 32 tests in `test_audioeditor.py` rather
#   than skipping them: they build a `Workbench` and `start` it, which
#   compiles, and none of them carried the guard.  Found by hiding clang
#   from `PATH` and running — the claim had been made from reading the
#   files that *did* carry it.
#
# * **cargo** — the editor's window and the CLAP export, both Rust.  The
#   window is a `cdylib` loaded through `ctypes` and builds itself on the
#   first `python -m gestate.workbench`; without cargo the editor refuses
#   and says what to run by hand.  `README.md` is the whole install.
#
#   *This bullet used to ask for **python3-tk**, for a Tk view inside
#   `gestate.audioeditor` that no longer exists — `shell/editor`
#   replaced it and `audioeditor` is the model half now.  `tkinter` is
#   not needed for anything here.*
#
# * **pw-play / paplay / aplay** — how `audiolive` reaches the speakers
#   when `sounddevice` is absent.  A test machine wants none of them, and
#   `conftest.py` shuts that door regardless.
