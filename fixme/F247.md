# F247. **[resolved]** a program that draws, includes a `.notes` as its score and plays through no bank refused in both halves: "Unknown type constructor: Voice"

**2026-10-03**, found porting the note hand (`card:gui-is-difficult.md`
§"Built — the notes editor's note hand").  `music.ges`' `Score` names
`Voice`, whose constructors only a `voices` bank generates
(`audiovoices._voice_type`), and gestate cannot declare a type with none
(F60).  `midi.py` gives a bankless piece the stub `Voice := NoVoice`; the
canvas half (`gui._preludes`) and the performance
(`audioscore.assemble_performance`) did not, so a canvas that includes a
`.notes` and plays through no bank refused to build — and its sound
refused with the same words about a type nobody can declare, rather than
saying the notes had no instrument.

**Resolved the same day:** `audiovoices.voice_stub`, used by both.  The
canvas half draws; the sound half now refuses for the reason that is
true (`No instance for FromNote Void` — the notes are given no
instrument).  Held by `test_gui.py`'s
`test_a_canvas_with_a_score_and_no_bank_compiles_both_halves`, red with
the stub removed.
