# F244. **[bug]** a one-line `case … of A -> a; B -> b` swallows the next top-level definition

**2026-10-02**, found when `gestate/reactors.py` generated its mode
chain on one line: the definition after it failed to parse, at a column
of a line that was not the `case`'s.

    python -c "import sys; sys.path.insert(0,'.'); from gestate.syntax import parse; \
      parse('f x = case x of True -> 1; False -> 2\n\ng y = y\n')"
    # expected '->', got 'y' (at 2:2)

`spec/monad.md` says a block's items *"sit at one column or split on
`;`"*, so the one-line form is promised; the block it opens is not
closed by a later line at column 0.  Flat or nested, with or without a
comment between, the same.

**Worked around, not fixed:** the reactor desugaring lays its `case`
out one alternative a line.
