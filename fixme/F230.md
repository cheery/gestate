# F230. **[resolved]** an error message about the buffer re-reads the file on disk into the bench's model, so the relations and origins after a reported failure are the saved file's and not the one being edited

Found 2026-09-13 while taking slice (a) of `card:gui-is-difficult.md`,
through a test that went red only because its steps got slower than
`AUDITION_WAIT`.

`Workbench._first_line` places a message with `_whole` → `in_source` →
`_source_text`, and `_source_text` is `self.program()` with no text —
so `self.source()`, the file on disk.  For a registered kind,
`program` is not a read: `NotesKind.program` assigns
`bench.notes_relations`, and `Workbench.program` assigns
`bench.origins`.  So formatting any error while the buffer and the disk
differ replaces the bench's model with the saved file's.  Whatever reads
the relations next — the tempo, `_load_score`'s schedule, the page's
rolls — reads what the person is no longer looking at.

**Witnessed on `arc.notes`**, headless: the buffer `bpm 96` + the file,
`bench.program(buffer)` gives `bpm_of(bench.notes_relations) == 96`;
`bench._first_line(ValueError("…"))` answers the message, and the
relations then say `bpm` is `None`.  In the suite it surfaced as
`test_tempo_writes_the_notes_record_and_rewrites_it_and_the_bench_plays_at_it`
reading 100 bpm: the coalesced audition's worker raised (the test's
stand-in took the wrong arguments), the report re-read the disk, and
`_load_score` was still running.

**Resolved the same day.**  `Workbench.program` remembers the program
it made last, and `_source_text` places a message against that — the
text the build was compiling, which its own docstring always said and
the disk never was.  Before any program is made it makes one and puts
back the `origins` and relations it overwrote.  The coalesced
worker's stand-in in the test that found it was corrected separately.

gate: `test_drawnscores.py::test_an_error_message_leaves_the_bench_holding_the_buffer_it_was_given`
— red on the defect; red with the remembered program ignored (a position
on a typed line placed in *the generated entry*) and red with the
fallback's restore taken out.
