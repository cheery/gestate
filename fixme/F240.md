# F240. **[resolved]** the first note played into a fresh plugin was silent on every plucked and struck bank, because a note stamped into the state's first block is read a block late

**Henri, 2026-09-16:** *"the exported CLAP plugin has a similar issue as
earlier on.  The first note is not playing (on channel 1) but now the
bar shows that the MIDI is going there.  Something else prevents it
from playing."*  And then: *"bowed instruments do produce sound on the
first MIDI note."*

Driven in the tests' ctypes host on `~/gestate.scratchpad/neatness.ges`
exported (`probes/clap/drive.py` beside it): on a fresh instance the
first note is silent for the pluck at any offset that keeps its
one-millisecond pick inside the block — 0, 1, 300 — and plays from the
next block when stamped at sample 511; the marimba is silent likewise;
the bowed comes up after 0.18 s, which is its own attack.  On an
instance that has rendered before, every bank plays at every offset.

**The cause is the engines' first instant, and it is by design there.**
`audioengine.render_block`: at `t == 0` every source takes its `init`,
and a control source is then held across the block — `0 ::: mkSig
(wait chan)`, the language's stream semantics — so the generated code
has the same `select %first, init, …`.  A note the shell stamps into
the state's first block is read at the *next* block's start; a
sustained voice loses its first block and is heard, a pick or a mallet
has decayed by then.  And with the transport stopped the shell renders
nothing until a key arrives, so the block a session's first key lands
in is exactly that first block.

## Resolved — 2026-09-16

**Not by stepping the state past its first instant** — that was the
first fix, and it put the plugin one sample ahead of every offline
render and every bake, which nine parity tests refused at once; the
bit-exact contract with the engine is worth more than a shortcut.
Instead, only a block that is the state's first *and* drained a note
is rendered as two calls: the first instant alone, which is the inits
exactly as offline, and the rest, at whose start the controls are
read.  Every other block is one call and bit-exact as before; the
engines are untouched, because the first instant is the language's.

gate: `test/test_export.py::test_a_click_in_the_first_block_a_fresh_plugin_renders_is_heard`
— a bank whose whole voice is a one-millisecond click, one fresh
instance, one note at the first sample of the first block; the first
block peaked at 0.000 before the fix and carries the click after, and
the eighteen other export tests hold, the nine bit-exact ones among
them.
