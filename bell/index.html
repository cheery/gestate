# A tubular bell, by modal synthesis — struck by chance.
#
#   python -m gestate.audioperform examples/audio/bell.ges -o bell.wav
#   python -m gestate.audioperform examples/audio/bell.ges --seconds 6
#
# **This is physical modelling, and it needs nothing the library did not
# already have.**  A struck bar or bell does not have a waveform; it has
# *modes* — frequencies at which the metal likes to vibrate — and each one
# is excited by the strike and then decays at its own rate.  A resonant
# bandpass filter rung by an impulse is exactly one such mode, so a bell is
# a handful of them summed.
#
# `spec/delaylines.md` sorts the three families of physical modelling:
# the *modal* one is this file, the *mass-spring* one is an ordinary
# `scan`, and the *waveguide* family — strings, tubes, brass — needed a
# delay line with a filter in its loop, which `loop` now is:
# `examples/audio/strings.ges` is Karplus-Strong on eight of them.

# ── The strike ───────────────────────────────────────────────────────────
#
# `dust` is random impulses at an average rate, and the rate is a *signal*
# — so a bell can be struck more often as the piece goes on.  Here it
# drifts between about one and three strikes a second over eight seconds,
# which is enough to stop the pattern being heard as a pattern.
#
# It is the whole excitation: a bell does not care how it was hit, only
# that it was.

strike : Sig Float
strike = dust 23 (2.0 + 1.0 * sine 0.125)

# ── The modes ────────────────────────────────────────────────────────────
#
# A tubular bell's partials are **inharmonic**, and that is what makes it a
# bell rather than a note: 1 : 2.76 : 5.40 : 8.93 are the classic ratios
# for a free bar, and no two of them are a whole number apart, so the ear
# hears metal instead of pitch.
#
# `resonate` is the filter this needs, and it exists because this example
# did not work without it.  Written first with `bandpassSvf` at maximum
# resonance, the bell **sounded like a woodblock** — measured afterwards,
# that filter's damping floor caps its ring at 0.503 s at 220 Hz however
# hard it is pushed, which is a marimba bar and not a bell.  `resonate`
# takes a decay time in seconds instead and will ring for as long as it is
# asked to.

#: One mode: a frequency, how long it rings, how loud it is in the sum.
mode : Float -> Float -> Float -> Sig Float -> Sig Float
mode hz seconds level s = !level * resonate (!hz) (!seconds) s

#: Four modes, at the ratios a real bar has, and **the decays are in
#: seconds** — which is how a bell is actually described.  The higher ones
#: die away first, which is what makes the attack bright and the tail pure:
#: the same idea `fmpoly.ges` gets from four envelopes on four operators.
bell : Float -> Sig Float -> Sig Float
bell f s = mode f              6.0 1.00 s
         + mode (f * 2.76)     4.5 0.70 s
         + mode (f * 5.40)     2.5 0.50 s
         + mode (f * 8.93)     1.2 0.30 s

# ── The output ───────────────────────────────────────────────────────────
#
# The bell alone peaks hard on a strike and is silent between, which is
# exactly what a compressor is for: `Comp 0.25 4.0` leaves the tail alone
# and takes 6 dB off the strike, so the ring is audible without the attack
# being painful.  `limit` after it holds the ceiling — approximately, and
# its own prose says by how much.

sound : Sig Float
sound = limit 0.9 (compress (Comp 0.25 4.0 0.003 0.25) (0.5 * bell 220.0 strike))
