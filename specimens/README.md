# Specimens

Programs that defeat the machinery in a known way, kept whole.

An example shows what the language can do; a specimen shows what it
cannot, yet.  Each file here is a real program somebody meant — not a
contrived crash — that found an edge worth keeping: a walk that
diverges, a layout that cannot finish, a sentence the language accepts
and no engine survives.  The header of each file names its defeat and
what it waits on.

Two rules hold the room together:

- **Nothing sweeps this directory.**  The suites build every example;
  a specimen diverges by design, and a test that forces one hangs the
  suite — which is precisely the behaviour being preserved for study.
  Run one deliberately or not at all.
- **A fixed specimen graduates.**  When the machinery learns the edge,
  the file leaves for the test that proves it stays learned, and this
  directory gets one file shorter.  Growth here is a debt ledger, not
  a collection.
